# Neural Universe

A browser-based, interactive 3D laboratory for brain-inspired computational neural networks.

## Development

Requires Node.js 20+.

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The initial prototype provides a Three.js neural field, a leaky integrate-and-fire simulation, excitatory/inhibitory neurons, delayed synapses and a basic STDP approximation. This is an experimental model, not a validated biological brain simulation.
